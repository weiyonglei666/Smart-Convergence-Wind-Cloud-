# 贡献指南

修改前请阅读 `LICENSE`，授权与数据访问咨询请联系 ts26170007a31@cumt.edu.cn。

提交代码时应满足：

1. 不提交场站数据、容量资料、训练权重、缓存、预测数组或私人服务器路径。
2. 保持默认预测长度为 16；变更模型或增强行为时在实现说明中说明，并提供对应测试。
3. 运行 `python -m unittest discover -s tests -v` 与 `python scripts/check_release.py`。
4. 任何新增实验明确记录未来气象是实测还是预报，不能混用输入条件比较后宣称公平部署精度。

本地发布工具只生成源码压缩包，不会创建远端仓库、推送代码或上传数据。
