# 实现与复现说明

## 当前整理版对应的实现

本版本提取当前正式 16 步分场站实验中的 `DynaForeNet`、`FeatureAwareAugment` 与本地 PVA/TRA 层，不混入早期版本的模型或基线适配器。来源文件及 SHA-256 记录见 `SOURCE_PROVENANCE.json`。

主模型保留的运算包括：非重叠 patch 的均值解耦；最新 patch 上跨变量 PVA；时间注意力值分量的均值恢复；内部 token 与最近 72 点统计的门控融合/AdaIN；rFFT 自适应谱门；1/2/4 尺度融合；未来气象/时间条件交叉注意力；最近功率状态残差输出；风电和独立光伏机理引导分支。

输出是容量归一化功率，风电在 forward 内约束到 `[0,1]`；光伏额外乘上辐照昼夜掩码。转为 MW 时乘以站容量。评估入口不再额外统一裁剪。

## 训练与消融

AutoDA 是本任务的可微适配：3 层策略 MLP，通过 Gumbel-softmax 选择恒等、幅值、功率平移、噪声、平滑及频率衰减操作，与预测器联合优化。幅值与平移操作对标签进行一致变换。它不是未经修改运行上游 AutoDA 全部算法。

细粒度重构在相邻历史点间创建 16 个虚拟相位，通过局部平均得到训练视图；不产生真实分钟级观测或新增真实监督标签。增强只在训练阶段使用，验证/测试没有增强。

为保持正式实验的数值行为，增强沿用原通道索引掩码：`[0:11]` 与 `[15:18]`。标准 17 通道输入中最后两项可能覆盖年度正余弦，因此**不能把该版本描述成所有日历通道都不扰动**。改变掩码属于新的方法变更，需要重新实验。本整理任务没有修改该行为。

训练损失为容量归一化 MSE + `0.15 × mean(sqrt((sum(|e|³)+1e-10)/(sum(|e|)+1e-6)))` + 增强熵/层间一致性正则。正则权重沿用 `0.001`。选择最佳 epoch 只看验证 ACC@16。

消融开关：

| 变体 | 与完整模型相比关闭的部分 |
|---|---|
| noPMD-PVA-TRA | patch 均值解耦、PVA、TRA 均值恢复；基础时间自注意力仍在 |
| noNSAN | 统计融合/AdaIN 模块；保留频谱与多尺度部分 |
| noAutoDA | 三层策略增强及其附属细粒度重构 |
| noguided correction | 风电/PV 机理引导残差；保留物理输出边界与昼夜掩码 |

## 指标

对样本-步长矩阵的全部 16 步误差计算 MSE、MAE 和 RMSE。nMAE = MAE / 容量，nRMSE = RMSE / 容量，以比值输出而不是百分数。

ACC 不是 `100 × (1-nRMSE)`。先对每个预测起点计算：

`ACC = 100 × (1 - sqrt(sum(|e|³) / sum(|e|)) / capacity_mw)`

再对起点求均值。全部误差为零时 ACC 为 100；负 ACC 不裁剪。R² 在全部 16 步点上计算；爬坡事件阈值为 `0.1 × capacity_mw`。MSE 的单位 MW²，MAE/RMSE 的单位 MW，ACC 单位 %。

## 从原实验到独立包的改动

- 移除绝对服务器路径和跨目录 `sys.path` 注入，改为 `--raw-dir`/`--output` 与包内相对导入。
- 只提取 DynaFore-Net 依赖的本地类，不打包完整上游基线库。
- 将历史功率的旧固定 `20 MW` 解码适配改为显式 `capacity_mw`；与原 runner 的 `20/capacity` 缓冲区变换数学等价，不改网络结构。
- 显式要求站容量，不沿用原代码缺少元数据时从整段功率估计容量的回退。
- 种子由显式基准 seed + 站号 SHA-256 派生，不使用进程相关的 Python `hash()`；不声称逐比特复现旧实验。
- 检查点以张量及普通字典/列表保存，评估用 `weights_only=True` 加载；保存最佳 epoch 对应的增强参数，但没有承诺优化器断点续训。
- CSV 日期解析区分 ISO 年优先与原日优先格式，以避免日期歧义。
- 增加独立测试、数据排除规则与发布前审计；不重新运行真实场站训练。

## 资源需求

数据准备目前与原实验一样显式保存所有有效滑动窗口，训练时还会构造标准化数组；长时段、多场站可能需要较大的内存与磁盘。按场站逐个运行以降低并发资源压力。`--max-train/--max-val/--max-test` 默认 0 表示不抽样；设置上限仅适用于调试，不应作为正式完整窗口实验。

20 epoch 是最大值，不是保证每个场站都执行 20 次。GPU 浮点差异和依赖版本也可能导致新实验不同于此前结果。
