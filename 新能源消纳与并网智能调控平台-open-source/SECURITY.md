# 安全策略

## 支持范围

安全修复优先覆盖默认分支的最新版本。生产部署方应自行维护数据库权限、网络隔离、密钥轮换、访问控制和审计策略。

## 漏洞报告

请通过 [ts26170007a31@cumt.edu.cn](mailto:ts26170007a31@cumt.edu.cn) 私下报告安全问题，并尽量提供影响范围、复现步骤和建议修复方式。请勿在公开 Issue 中粘贴密码、Token、私钥、生产地址或业务数据。

## 凭据管理

仓库不接受任何真实凭据。请使用本地 `.env`、操作系统凭据库或专用密钥管理服务，并在发生误提交时立即吊销和轮换相关凭据，而不是仅从 Git 历史中删除文本。
