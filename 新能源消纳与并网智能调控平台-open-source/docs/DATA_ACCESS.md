# 数据接入与使用说明

## 未随仓库发布的内容

- 风电、光伏场站实时与历史功率数据；
- 超短期功率预测结果；
- 测风塔、辐照度等历史气象观测；
- NWP 原始 GRIB/NetCDF 文件和裁剪结果；
- 电力调度、气象和案例知识库；
- 模型权重、向量索引、评测集及生产日志。

上述内容可能包含业务敏感信息、第三方许可数据或大体量文件，因此仅保留接入接口和目录占位，不进入 Git 历史。

## 接入原则

1. 数据库使用最小权限只读账号，凭据通过本地 `.env` 或密钥管理服务提供。
2. 预测结果表的业务方命名前缀通过 `FORECAST_TABLE_PREFIX` 配置，不应硬编码在公开源码中。
3. 历史测风塔和辐照度数据按其原始 UTC+8 时间使用；NWP 原始 UTC 时间转换为 UTC+8 后再对齐。
4. NWP 应依据场站经纬度裁剪最近网格，并保留起报时间、有效时间和源文件追踪信息。
5. 数据缺失、口径异常与限电标记必须显式呈现，不应通过伪造或插值形成虚假实时状态。
6. 数据使用方应自行确认授权范围、保留期限和脱敏要求。
