## 知识库

本地 `data/corpus/` 放置有合法使用权的 UTF-8 `.txt` 文件，可包含子目录。
建库脚本不会自行下载任何资料。PDF请先在本地提取正文并核对抽取质量。

## 评测集

本地 `data/benchmark/` 放置JSONL，每行一个对象，支持 `question` / `answer`
或 `input` / `output` 字段；可选 `index_class` 表示问题类别。
文件名和行号共同构成 item_id，因此实验期间不能重排文件。
知识库不得包含评测问题的参考答案。

不附带真实样本；测试中的短文本为程序验证所用的合成夹具，不是评测数据。
